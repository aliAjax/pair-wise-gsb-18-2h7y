# hxwl-04 牙科根管治疗

根管治疗后夜间来电的电话分诊与椅位复诊排程。

## 技术栈

React + Vite + TypeScript + CSS

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5104

## 电话分诊功能

前台接到来电（典型场景：根管治疗后第二晚跳痛或咬合痛）后：

1. **登记**：患者、电话、牙位（FDI）、来电时刻、疼痛分值（0–10）、疼痛性质、夜间痛、肿胀/发热、术后第几晚。
2. **系统判断复诊时限**（纯规则，见 `src/triage/triageRules.ts`）：
   - **急救·当天处理（来电后 4 小时内）**：面部肿胀 / 发热 / 夜间痛且 ≥7 分 / 跳痛且 ≥7 分 / 咬合痛且 ≥6 分；
   - **加急 24 小时内**：夜间痛、跳痛、咬合痛 ≥4 分或疼痛 ≥5 分；
   - **常规 72 小时内**：术后轻度酸胀，含电话宣教与升级提示。
3. **急救待排**：急救记录登记后自动按复诊时限找椅位时段；排不进则进入等待区，卡片写清冲突原因。
4. **椅位时段**：30 分钟一个槽位（09:00–18:00，三台椅），同一牙椅同一时段只留一人；可自动派位、手动指位，也可在看板点空格直接排入。
5. **医生确认接诊**：在看板点“接诊”，登记医生与实际处理（调合 / 冲洗换药 / 根管再处理 / 开放引流 / 观察），预约标记为已接诊。
6. **改约**：必须填写原因，原时段、新时段、经办人与原因全部留痕（台账页可查），原预约标记为“已改约”。
7. **本机保存**：所有资料存浏览器 localStorage（键 `hxwl-04-triage-v1`），关掉页面/浏览器后重开仍能接着排；右上角可重置为演示数据。

## 代码分层

| 层 | 文件 | 职责 |
| --- | --- | --- |
| 资料 | `src/triage/types.ts`、`src/triage/time.ts` | 字段类型、牙椅/槽位与时间工具 |
| 初始资料 | `src/triage/storage.ts` 的 `seedState` | 首次打开的演示数据（含一例排不进等待区的急救） |
| 判断 | `src/triage/triageRules.ts` | 症状 → 紧急级别 / 复诊时限 / 分诊意见（纯函数） |
| 判断 | `src/triage/scheduleRules.ts` | 椅位槽位冲突判定、自动派位（纯函数） |
| 本机保存 | `src/triage/storage.ts` | localStorage 读写、版本与损坏回退 |
| 状态 | `src/triage/store.tsx` | 页面动作入口，组合判断与保存 |
| 页面 | `src/components/*`、`src/App.tsx` | 登记表、队列/等待区、椅位看板、弹窗、台账 |

判断规则不依赖 React 与存储，可单独核对或替换为后端接口。
