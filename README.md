# 根管术后来电分诊

根管治疗后第二晚跳痛/咬合痛来电的电话分诊与急救待排工具：前台登记患者、牙位、
来电时刻、疼痛分值与夜间痛，系统按症状自动给出复诊时限并安排椅位；数据只保存在
本机浏览器，关掉页面后再打开仍能接着排。

## 功能

- **电话登记**：患者、FDI 牙位、来电时刻、疼痛分值（0-10 滑杆）、夜间痛等 8 项症状
- **分诊判断**：登记时即时预览，提交后保存判断快照（等级、复诊时限、依据、电话指导）
  - A 级 急症：剧烈疼痛（≥8）、跳痛+夜间痛、肿胀、发热、张口受限 → 当天门诊结束前
  - B 级：跳痛/自发痛、咬合痛叠加夜间痛或中重度疼痛 → 24 小时内
  - C 级：咬合痛、咬合高点、中度疼痛或轻度夜间痛 → 72 小时内
  - D 级：术后轻度反应性疼痛 → 7 天复查期内观察
- **急救待排**：当天需处理的 A 级单列，按截止时刻排序并显示剩余时间
- **椅位号表**：同一牙椅同一时段只留一人；自动排入时限内最早空闲时段
- **等待区**：时限内排不上时留在等待区，写清具体冲突（哪个时段四台椅位全满、被谁占用）；
  释放椅位后可一键重新自动排椅，也可手动选空格排入
- **接诊闭环**：医生确认接诊 → 记录实际处理并完成
- **改约**：保留原时段（椅位/日期/时间）与改约原因，旧时段自动释放
- **留痕**：登记、排椅、等待区、改约、接诊、完成全部写入操作时间线
- **本机保存**：localStorage 持久化，支持多个浏览器窗口之间实时同步

## 技术栈

React 19 + Vite + TypeScript + CSS，无后端。

## 本地运行

```bash
npm install
npm run dev      # http://localhost:5104
npm run build    # 类型检查 + 生产构建
```

## 代码结构（资料 / 判断 / 本机保存 / 页面分开）

```
src/
├── triage/                 # 与页面无关的领域逻辑
│   ├── types.ts            # 资料：领域类型（来电记录、症状、椅位占用、状态…）
│   ├── symptoms.ts         # 资料：症状字典
│   ├── time.ts             # 资料：门诊日历与时间纯函数
│   ├── rules.ts            # 判断：症状分级与复诊时限规则（纯函数）
│   ├── schedule.ts         # 判断：椅位网格、空闲检索、冲突说明（纯函数）
│   ├── storage.ts          # 本机保存：localStorage 读写、跨窗口同步、演示数据
│   ├── store.ts            # 编排：登记→分诊→排椅→保存的状态钩子
│   └── format.ts           # 纯展示格式化
├── components/             # 页面
│   ├── CallForm.tsx        # 来电登记（含实时分诊预览）
│   ├── QueuePanel.tsx      # 急救待排 + 等待区
│   ├── ChairBoard.tsx      # 椅位时段号表
│   ├── RecordModal.tsx     # 记录详情：接诊、实际处理、改约、留痕
│   └── RecordsList.tsx     # 全部来电记录
└── App.tsx                 # 页面组装
```

首次打开会播种两条演示数据（已排椅的急症、排不进等待区的急症），可用页脚
"恢复演示数据"重置；所有规则阈值集中在 `src/triage/rules.ts`，门诊时段与牙椅数量
分别在 `time.ts`、`schedule.ts` 顶部配置。
